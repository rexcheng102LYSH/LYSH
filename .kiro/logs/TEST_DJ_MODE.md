# DJ 模式測試指南

## 🎮 如何測試 DJ 三階段系統

### 準備工作

1. 在瀏覽器中打開 `index.html`
2. 點擊任意處啟動音效系統
3. 開始一局遊戲（PvE 或 PvP）

### 設置 DJ 特效

1. 點擊右上角的 🎨 按鈕打開皮膚菜單
2. 在「勝利特效」區域選擇 **🎵 DJ**
3. 關閉菜單

### 測試流程

#### 階段一：挑戰模式（完美通關）

1. **獲得勝利**
   - 完成五子連珠
   - 畫面會出現聚光燈和鼓

2. **聽音樂**
   - 等待 1 秒，挑戰旋律開始播放
   - 旋律：C-D-E-G-E-D-C-G（8個音符）
   - 同時有 Bass 和 Hi-hat 背景節奏

3. **跟隨節奏擊鼓**
   - 每 0.6 秒會有一個節拍
   - 總共 8 個節拍需要擊打
   - 在節拍到來時點擊屏幕任意位置
   - 判定窗口：±150ms

4. **視覺反饋**
   - ✅ 完美擊中：
     - 鼓面膨脹
     - 屏幕閃白
     - 粒子爆發
     - 播放 Kick 音效（強勁底鼓）
   - ❌ 失誤：
     - 播放 Miss 音效（走調音）

5. **完美通關**
   - 8 個節拍全部擊中
   - 自動進入勝利階段

#### 階段二：失敗模式（故意失誤）

1. **重新開始一局**
2. **獲得勝利後**
   - 故意不點擊，或提前點擊
   - 錯過 1 個或以上節拍

3. **失敗效果**
   - 畫面逐漸被黑暗吞噬
   - 聚光燈和鼓消失
   - 只剩下勝利選單可見
   - 播放悲傷的失敗音樂

#### 階段三：勝利模式（完美通關後）

1. **完美通關 8 個節拍後**
   - 畫面變成華麗的漸變背景
   - 聚光燈加速旋轉
   - 顯示金色 "PERFECT!" 文字

2. **自動演奏**
   - 鼓會自動擊打（每 0.6 秒）
   - 播放勝利進行曲（12 個音符）
   - 持續約 7 秒

3. **視覺效果**
   - 勝利粒子噴泉（50 個粒子）
   - 鼓的自動彈性動畫
   - 持續的聚光燈旋轉

4. **結束**
   - 約 10 秒後顯示勝利選單
   - 可以選擇「再來一局」或「主菜單」

### 🐛 常見問題

**Q: 聽不到音樂？**
A: 確保點擊了頁面任意處啟動音效系統，檢查瀏覽器音量。

**Q: 點擊沒反應？**
A: 確保在挑戰階段（有聚光燈和鼓），失敗或勝利階段不接受點擊。

**Q: 節拍太快/太慢？**
A: 當前設置為 100 BPM（0.6秒/拍），可在 `audio.js` 中調整 `beatDuration`。

**Q: 判定太嚴格？**
A: 當前判定窗口為 ±150ms，可在 `audio.js` 的 `djPlayerHit()` 中調整 `hitWindow`。

### 🎨 自定義選項

#### 調整難度
在 `audio.js` 中修改：
```javascript
djGame: {
    totalBeats: 8,        // 改為 6 或 10
    beatDuration: 0.6,    // 改為 0.5 (更快) 或 0.8 (更慢)
}
```

#### 調整判定窗口
在 `audio.js` 的 `djPlayerHit()` 中：
```javascript
const hitWindow = 0.15; // 改為 0.2 (更寬鬆) 或 0.1 (更嚴格)
```

#### 調整旋律
在 `audio.js` 的 `playChallengemelody()` 和 `playVictoryMelody()` 中修改音符數組。

### 📊 性能指標

- **挑戰時長**：約 5-6 秒（8 拍 × 0.6 秒）
- **總體驗時長**：約 10 秒（挑戰 + 勝利演奏）
- **判定精度**：±150ms
- **幀率**：60 FPS
- **音頻延遲**：< 50ms
