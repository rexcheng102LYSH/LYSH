极简模式：像游戏存档一样用

先学 4 个按钮：快存、查看存档、安全读档、恢复分支。

发布向导

步骤 A：填写发布信息并提交到 Git history

步骤 B：清除版本提交前的所有 stash

步骤 C：可选给这次发布打 Tag（推荐）

小白提示：

1. 先点“一键快存”，相当于手动存档。

2. 出问题时点“安全读档最新”。

3. 不放心就先“创建恢复分支”。
